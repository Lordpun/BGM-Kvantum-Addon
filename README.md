#BGM Kvantum Addon

This is an addon for my Background Manager script
It's designed for the theme I personally use, which is Glassy-KDE by Pr0cella 

## Dependiences

* Python
* Kvantum
* [Glassy-KDE](https://github.com/Pr0cella/glassy-kde)
* [My Background Manager script](https://github.com/Lordpun/Background-Manager)

## Installing

Run `git clone https://github.com/Lordpun/BGM-Kvantum-Addon` or download the files off of the releases page

Add the path of run.sh to addons.json in ~/.config/BgManager/

Formatted as
```
[
  "/home/user/path/to/BGM-Kvantum-Addon/run.sh"
]
```

You can also add `ChangeKvantum: bool` to your config.json to disable or enable it
By default, it's marked as true
